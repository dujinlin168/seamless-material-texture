# 制作材质无缝贴图

利用当前 Codex 环境已有的生图与图像处理能力，制作满幅、正视、均匀受光、可重复铺贴的独立色彩贴图。默认交付 Color / Base Color，不将灰度转换称为实测法线、粗糙度或位移贴图。

本技能提供材质制作方法，不附带生图服务、账号或固定执行器。遵循当前环境的系统规则、用户约定及工具说明，不引入作者电脑的路径、接口、模型、密钥或其他 Skill 依赖。

## 1. 接入现有生图流程

- 用户已指定工具、模型或工作流时沿用，并读取必要使用说明；未指定时采用当前环境已配置且适合任务的能力，不让用户重复配置可用环境。
- 有参考图时，确认所选能力支持并真正传入参考图；指定表面、蒙版和保留要求随输入传递。只有文生图能力时，说明缺少参考输入能力，不能默默将参考提取改成文字猜测；只有用户接受近似创作后才改变任务。
- 无参考的原创材质可文生图；只需处理已有贴图时直接使用已有图像处理能力。
- 不固定 API 地址、模型、请求字段、操作系统、解释器或安装目录；调用方式由现有工具决定，不需要作者的历史请求证据。
- 生图与后处理是不同能力。可使用环境已有库完成可逆本地处理；需要新依赖、账号或服务时准确说明缺少项，不假定已经存在，不自动安装或更改账号配置。
- 当前制作请求通常对应一个材质、一个候选。未授权批量或多轮时，不自动追加生成、换服务或重试；已有用户预算和批量约定优先。不要仅为测试能力发起付费请求。
- 确实提交后才说明正在生成；超时且结果未知时只追踪原任务，不重发。未取得可验证产物时，不以旧图片或说明文字冒充结果。

## 2. 确定材质与规格

查看参考，确定目标表面、底色关系、纹理形态、粗细、密度、方向和对比。箭头只用于定位，不能进入纹理。目标无法从上下文确定时，只询问缺少的关键信息。

- 用户指定的像素、长宽比、实物尺寸和方向优先。毫米表示模型中的映射尺寸，像素表示文件分辨率，分别记录。
- 未指定像素时采用现有生图流程常用且支持的尺寸，通常为方形；记录实际返回尺寸，不继承作者的个人像素规格。
- 未指定实物尺寸时不臆造真实比例，注明“映射尺寸待用户在建模软件中设定”。有可靠尺寸依据可给建议，并写明依据。
- 原生输出受限制时保留原图。裁切、重采样另存并披露，不拉伸改变纹理形状，不将插值称为新增原生细节。
- 瓷砖、拼花等材质先明确一张贴图代表的重复单元。保留设计需要的砖缝与排列，避免平铺边界叠出双倍宽度的缝。

用一句话说明本轮对象、净化内容和保留特征，然后执行。

## 3. 净化与提示词

默认去除物体构造和场景影响：柜门边框、拉手、五金、无关分格缝、周围物体、透视、投影、环境明暗渐变和光斑。排除箭头、标注及无关文字，尊重输入素材的使用权限。

保留底色关系、自然色差、纹理方向和合理尺度。纯木纹的柜门拼缝属于应去除构造；瓷砖砖缝、织物组织与拼花属于设计纹样，不能一律消除。用户明确保留的内容按要求处理。

提示词按“参考角色 → 材质特征 → 规格方向 → 独立正视贴图 → 排除项 → 周期衔接”组织，例如：

> 参考图只用于匹配指定门板的暖棕色、细直木纹和克制的自然色差。制作满幅、正视、均匀受光的独立木纹色彩贴图，纹理纵向，比例和分辨率采用本次确定规格。去除门框、拉手、柜门拼缝、透视、阴影、高光、箭头和文字。保留自然木纹，不做镜像花纹。左右与上下连续衔接，避免亮带、明显重复块和糊块。输出一张独立纹理，不输出房间或多格平铺预览。

提示词写了“无缝”不代表验收通过。不要声称从普通照片恢复了精确色号、实测反照率或真实微观物理参数。

## 4. 检查与修正

候选返回后读取 [验收方法](references/quality-check.md)，实际检查文件与画面。

先做不修改原图的平铺检查，再针对缺陷选择最小修正。可使用现有的偏移、接续、颜色整理等能力，不要求某种软件或库。随机纹理可酌情修正低频明暗，规则图案须保持周期和结构。镜像复制、强行令边缘像素相等或大范围模糊不是通用无缝方法。

同一目标内常规可逆本地处理可直接完成，保留处理前文件，修改后重查。连续两次修正无改善时复盘方法，不无限试错。需要额外生成而没有授权、参考不足或无法完成必要检查时，报告具体阻碍。

## 5. 保存与交付

在用户项目的版本目录中保存原输入、生成原图和处理结果，按项目习惯使用 R1、R2 等，避免覆盖。技能安装目录不存业务图片。

正常交付：

1. 一个明确的最终色彩贴图文件，优先 PNG。
2. 2×2 或更大的平铺检查预览。
3. 简短检查记录：实际像素、原生与重采样区别、已知或待定映射尺寸、生成工具、生成次数、处理方法、技术与视觉结论、剩余限制。

能访问文件时记录大小与 SHA-256，检查记录绑定最终文件。工具提供请求编号或返回记录时留存可用证据并脱敏；内置工具未暴露原始请求时如实说明，不伪造日志，不因此要求换工具。

所有适用检查通过才称“已检查的成品”。缺少平铺或原生尺度接缝检查时为“候选，接缝待验证”；可见缺陷为“不通过”。不默认展示失败候选，但说明未完成原因。

最终回复突出成品、像素、映射说明、用途和验收结论。未在用户建模软件实贴，不声称已验证软件映射；二维平铺通过不保证任何场景中都看不出重复。
