# 材质贴图验收方法

检查准备交付的最终文件。状态为“通过 / 不通过 / 待验证 / 不适用”，不适用需有理由。技术与视觉分别判断。

## 技术

- 实际打开或解码文件，读取尺寸、格式、模式和大小，不以请求参数代替返回尺寸。
- 核对比例、方向与用户规格，记录裁切或重采样。原生尺寸硬要求不能用插值满足。
- 保留输入和生成原图，输出另存；可读取字节时记录哈希。最终修改或复制后确认交付文件与被检查文件一致。
- 只有预览而没有可下载或保存文件时，说明交付文件尚未取得。

## 材质

- 对照参考，检查色相、明暗关系、形态、方向、密度和粗细。平均颜色接近不等于材质匹配。
- 检查边框、五金、无关分格、场景物体、透视、投影及光斑残留；保留要求内的砖缝、拼花或织物组织。
- 取色选目标表面无遮挡区域，排除箭头、阴影和高光。图像取样不是实测色号。
- 无参考原创请求的参考匹配项为“不适用”，仍检查文字要求。

## 无缝

1. 同一张最终贴图按原方向、无间隔重复成至少 2×2，不镜像、不旋转来掩盖接缝。查看全幅颜色分布与重复块。
2. 在最终图像 100% 像素尺度查看完整横缝、竖缝与四角交汇。大图可用有重叠的分段裁切覆盖完整边界；工具自动缩图不能当作原生尺度检查。
3. 检查亮度跳变、断纹、网格、镜像、色带、糊块、重复斑点和后处理的内部接续痕迹。
4. 砖缝等设计边界允许可见，但排列、宽度、周期必须连续。设计纹样本身不是缺陷，“本来有缝”也不能掩盖错位。

边缘差值小或像素相等仅为辅助。漂亮的单张、缩略图或模型的自我描述不代替平铺检查。

## 结论

记录最终文件、检查图、查看尺度及覆盖范围。修改像素或尺寸后原视觉结论失效，重做相关检查。

未看图或未覆盖完整接缝：待验证。可见缺陷：不通过。所有适用技术、净化、材质与接缝检查通过后放行。用户要求提前预览可展示候选并标状态。

环境无法拼图、查看图片或检查文件时，列明缺少的能力及已完成部分，可提供候选与检查方法，不能承诺无缝已验收。
