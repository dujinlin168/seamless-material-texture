# 制作材质无缝贴图 Skill

面向已经使用 Codex、并具备生图能力的设计师。

沿用你现有的生图流程，完成材质提取、纹理净化和平铺接缝检查，不绑定特定模型、API 服务或作者的电脑环境。

## 可以做什么

- 从照片或效果图中提取指定区域的材质。
- 制作木纹、石材、墙面、织物等独立色彩贴图。
- 去除不需要的边框、拉手、五金、透视、阴影和光斑。
- 保留材质本身的纹理、方向和自然色差。
- 检查平铺后的接缝、颜色跳变和明显重复痕迹。

## 使用条件

- 已安装并使用 Codex。
- 已有可用的生图能力。
- 参考图提取需要工具支持图片输入。
- 完整验收需要可用的图像处理与看图能力。

本项目不提供生图账号、API 密钥或生成额度。

## 下载与安装

1. 点击本页面上方的绿色 Code 按钮。
2. 选择 Download ZIP，下载整个仓库。
3. 解压文件。
4. 将解压目录提供给 Codex，并发送下面这段话：

> 请阅读这个目录中的“先读我_安装与使用.md”，将 seamless-material-texture 安装到当前 Codex 支持的技能目录。先检查同名技能，不要直接覆盖。沿用我现有的生图能力，不修改供应商或账号配置。安装后检查文件结构和可发现性，不要为了测试安装而生成图片。

详细说明见：[安装与使用说明](先读我_安装与使用.md)。

## 使用示例

附上参考图，并指出目标区域：

> 使用 $seamless-material-texture，提取箭头指向的柜门木纹，去掉边框、拉手和光影，制作独立可平铺色彩贴图。沿用我现有的生图流程，输出后检查平铺接缝。

如果需要确定实物映射尺寸，可以补充：

> 这张贴图映射宽 1200 毫米、高 2400 毫米，纹理纵向。

没有参考图时，也可以描述原创材质：

> 制作一张暖灰色细砂墙面无缝色彩贴图，明暗均匀、纹理细腻，不要明显重复斑点。

## 交付内容

正常完成时包括：

- 一张最终色彩贴图。
- 平铺检查预览。
- 实际像素、映射说明和简短检查结论。

## 当前验证范围

当前为 R1 分享版。

已完成文件结构、内部引用、本机依赖残留和压缩包完整性检查，尚未完成不同用户环境下的真实生图验证。

未经过接缝检查的图片应标为候选，不能直接称为已验收无缝成品。

## 使用边界

- 默认输出 Color / Base Color 色彩贴图。
- 不默认包含法线、粗糙度或位移等 PBR 通道。
- 实际效果取决于生图工具、参考素材和任务要求。
- 二维平铺检查不能代替建模或渲染软件中的实际检查。
